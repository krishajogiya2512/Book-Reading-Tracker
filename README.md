# BookNest – Book Reading Tracker

BookNest is a modern and interactive book tracking web application designed to help readers organize their reading journey, discover new books, and track reading progress in a beautiful and user-friendly interface.

## Features

### Home Page
- Modern and responsive landing page
- Elegant hero section
- Smooth navigation between pages
- Clean and reader-friendly design

### Library
- Browse books across multiple genres
- Categorized collections:
  - Fiction
  - Romance
  - Thriller
  - Self-Help
  - Business
  - Non-Fiction
- Attractive book cards with cover images
- Easy exploration of book collections

### Reading Tracker
- Add books to your reading list
- Track reading progress
- Manage reading status:
  - Currently Reading
  - Completed
  - To Be Read
- Monitor pages read
- View reading statistics

### Dashboard Analytics
- Books Currently Reading
- Books Completed
- Books To Be Read
- Total Pages Read
- Real-time reading insights

### User Experience
- Responsive design for all devices
- Modern card-based layout
- Soft reading-inspired color palette
- Smooth animations using GSAP
- Clean typography and intuitive navigation

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/krishajogiya2512/Book-Reading-Tracker.git
```

### Navigate to the Project

```bash
cd Book-Reading-Tracker
```

### Run the Project

Open `index.html` directly in your browser or use the VS Code Live Server extension.
